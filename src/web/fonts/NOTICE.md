# Bundled fonts

The webfont binaries served by this site are base64 payloads inside
`src/web/font-files.ts`, generated by `scripts/build-fonts.ts`. This file is the
copyright notice that the SIL Open Font License requires to travel with them.
The licence text itself is `OFL.txt` in this directory.

All three families are licensed under **SIL Open Font License, Version 1.1**,
which permits redistribution, embedding and subsetting, including as part of a
larger work, provided the notice below and `OFL.txt` are included and the fonts
are not sold on their own. Subsetting is explicitly allowed; none of these
families carry a Reserved Font Name that the subsets violate, because the
subsets keep the original family names and are not modifications of the
outlines.

Full licence text: <https://openfontlicense.org/open-font-license-official-text/>

- Version: 6.101
- Upstream: <https://github.com/google/fonts/tree/main/ofl/charissil>
- Designer's page: <https://software.sil.org/charis/>
- Faces shipped: regular, bold, italic, bold italic
- Shipped bytes: 157,204 (woff2 + woff, subset)

Chosen as the site default. The brief asked for "ChareInk", a MobileRead forum
modification of Charis SIL distributed as zip attachments to forum posts. That
has no signed release, no version history and no verifiable provenance, so it is
not something to put in a supply chain. Charis SIL is the OFL original ChareInk
derives from, published by SIL with a version number, and it was designed for
long-form reading on low-resolution output in the first place.

## Derived artwork

The site icon (`src/web/icon-files.ts`, drawn by `scripts/build-icon.ts`) is an
"HN" ligature built from the Charis SIL Bold outlines for `H` and `N`, moved so
the two letters share a stem and emitted as SVG path data. It is a picture, not
a font: it contains no font tables, exposes no glyph a text engine could set,
and carries no family name. The OFL treats that as permitted use of the font
rather than a modification of it - the licence's own FAQ is explicit that
converting glyphs to outlines inside a document or a logo does not make the
result Font Software, and the Reserved Font Name clause therefore does not bite.

Attributed here anyway, because it is Charis SIL's drawing and SIL should be
named for it.

## Not bundled

**Bookerly** is offered in the settings modal as a `local()`-only option. It is
Amazon's proprietary e-reader typeface: present on Kindle hardware, licensed for
use on that hardware, and not redistributable. Choosing it emits no `@font-face`
and downloads nothing; on a device without it the stack falls through to
Georgia and then to the generic serif.

**Georgia** and the system sans stack are likewise references to fonts already
on the device. Nothing is shipped for them.
